## 数据表字段

| 表 | 关键字段 | 作用 |
|---|---|---|
| customers.csv | 客户ID | 客户画像主表，按客户ID补全客户相关字段 |
| merchants.csv | 商户名称、是否高风险MCC、商户城市 | 商户主表，按商户名称补全 MCC、高风险标识和商户城市 |
| customer_transactions.csv | 客户ID、交易ID、交易角色、交易顺序 | 客户到交易的多对多映射表 |
| transactions.csv | 交易ID、客户ID、交易时间、交易金额、交易渠道、交易类型、商户名称、交易城市 | 交易事实表，交易ID命中时该行的客户ID与事实字段为准；交易城市应与商户表商户城市一致 |

## 填写口径

- 交易ID 在 transactions.csv 中命中时，客户ID、商户名称、交易金额、交易时间、交易渠道、交易类型以表内数据为准，页面会自动回填并还原手改值。
- 交易ID 未命中时按新建交易处理，以上字段沿用用户填写值，模型风险分与近7日入出账比标记为不可用。
- 交易ID 命中样例或历史交易时，历史交易的 ID 形如 `TXN2026090001-H27`，同样按交易表回填。

## 进入提示词的上下文分块

| 分块 | 内容 | 模型用法 |
|---|---|---|
| 用户输入 | 客户ID、交易ID、商户名称、交易金额、交易时间、交易渠道、交易类型、补充说明 | 事实字段；命中交易表时以表内为准，会标注"已按交易表还原" |
| 客户表补全 | 拆成"规则引用字段"（发卡距今天数、卡片状态、常驻城市）和"画像背景"两行 | 只有规则引用字段可作为判定依据 |
| 商户表补全 | 商户MCC、是否高风险MCC、商户城市 | 交易城市属于商户属性 |
| 系统计算特征 | 是否夜间、是否跨区域、近7日/30日各类笔数、近7日入出账比 | R2-R7 的输入 |
| 历史行为基线 | 历史交易笔数、历史金额中位数、历史金额均值、历史夜间/线上/跨区域/高风险MCC占比、本次金额/历史中位数 | 判断是否偏离历史，R7 用倍数 |
| 近期交易明细 | 本次之前最近 8 笔的表格（不含本次） | 供核对基线，不重复计算 |
| 风险模型输出 | 模型风险分参与定级；规则命中数、模型版本、更新时间标为"外部模型附带说明（不参与判定）" | R8/R9 用模型分档 |
| 数据完整性 | 缺失项清单 | 非空即触发 R10 |

`客户分群` 不进模型输入：它与 72 笔人工标签完全对应（异常活跃=高18、需关注=中18、稳定客户=低36），属于标签泄漏字段，页面仍展示但提示词里剔除。
| fund_flows.csv | 客户ID、流水时间、收支方向、金额 | 资金流水事实表，用于计算近7日入出账比 |
| risk_model_scores.csv | 交易ID、模型风险分、规则命中数 | 独立风控模型输出表，不允许用户填写 |
| sample_transaction_labels.csv | 交易ID、派生统计、模拟风险等级、模拟标签 | 原始72笔样例标签备份，用于对照评价 |
